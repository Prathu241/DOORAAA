### To start PHASE 2 (training):
```bash
pwsh phase_2_train.ps1
```

Or manually:
```bash
cd microWakeWord
python -m microwakeword.model_train_eval \
    --training_config "../training_parameters_DORA.yaml" \
    --train 1 --restore_checkpoint 0 \
    --test_tflite_streaming_quantized 1 \
    mixednet \
    --pointwise_filters "64,64,64,64" \
    --repeat_in_block "1,1,1,1" \
    --mixconv_kernel_sizes "[5],[7,11],[9,15],[23]" \
    --residual_connection "0,0,0,0" \
    --first_conv_filters 32 --first_conv_kernel_size 5 --stride 3
```

Expected: 60–90 minutes, outputs quantized model (~40 KB)
