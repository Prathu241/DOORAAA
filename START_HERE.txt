═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "model_data.h: No such file"
  → Run: python convert_model_for_esp32.py

Problem: "TensorFlowLite_ESP32.h: No such file"
  → Install library in Arduino IDE (Tools → Manage Libraries)

Problem: Dashboard shows "DEMO MODE"
  → Close Arduino Serial Monitor
  → Restart Terminal 1 (bridge)

Problem: "Port COM11 busy"
  → Close Arduino Serial Monitor completely

Problem: RMS stuck at 1.0
  → Hardware wiring issue (check GPIO pins)
