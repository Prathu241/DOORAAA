🔌 BACKEND API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════

GET /api/metrics
  Returns: Current training metrics (step, accuracy, recall, precision, loss, batch)
  Source: Reads training_log_live.txt

GET /api/hardware-status
  Returns: ESP32-S3 status, INMP441 signal, temperature, firmware version
  Source: Hardcoded (can connect to real device)

GET /api/training-progress
  Returns: Historical training data (last 100 updates)
  Source: Reads training_log_live.txt

GET /api/model-status
  Returns: Quantized model file info and path
  Source: Checks trained_models/DORA/ directory
