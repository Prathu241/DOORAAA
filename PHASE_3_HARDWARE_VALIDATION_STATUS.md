### What's Included

**1. Microphone Capture Firmware (mic_test.ino)**
- Configures ESP32-S3 I2S in slave mode
- Reads from INMP441 @ 16 kHz, 32-bit I2S frames
- Converts 24-bit packed audio → 16-bit PCM
- Calculates RMS, peak, min, max statistics
- Outputs metrics every 500 ms to serial

**2. Hardware Wiring Guide**
- ESP32-S3 GPIO assignments:
  - GPIO 4: Bit Clock (SCK)
  - GPIO 5: Word Select (WS/LRCK)
  - GPIO 6: Data In (SD)
- INMP441 pinout (VCC, GND, L/R, SCK, WS, SD)
- Breadboard connection diagram
- 0.1 µF capacitor recommendation (noise filtering)

## USAGE INSTRUCTIONS

### For User (Hardware Owner)

1. **Gather Hardware:**
   - ESP32-S3 DevKit (with USB cable)
   - INMP441 I2S microphone module
   - Breadboard
   - 6× Female-Female jumper cables (DuPont connectors)
   - Optional: 0.1 µF capacitor

2. **Install IDE:**
   - Download Arduino IDE from arduino.cc
   - Install ESP32 board package
   - Select: Tools → Board → "ESP32-S3 Dev Module"

3. **Copy Firmware:**
   - Open Arduino IDE
   - Copy-paste contents of `/ESP32_MIC_TEST/mic_test.ino`
   - Save sketch

4. **Wire Hardware:**
   - Follow `/WIRING_QUICK_REF.txt` breadboard diagram
   - Double-check connections:
     - VCC → 3.3V
     - GND → GND (2 connections)
     - GPIO 4 → SCK
     - GPIO 5 → WS
     - GPIO 6 → SD
     - GND → L/R (mono)

5. **Upload & Test:**
   - Connect ESP32-S3 via USB
   - Click Upload in Arduino IDE
   - Open Serial Monitor (Tools → Serial Monitor, 9600 baud)
   - Verify output appears
   - Speak "DORA" into microphone
   - Observe RMS/peak values change

6. **Report Result:**
   - If values change with speech: **STATUS: MIC PASS**
   - If all zeros or no output: Troubleshoot per README

## RISK MITIGATION

| Risk | Mitigation |
|---|---|
| Microphone not working | Pre-validation: Ensure I2S wiring is solid |
| USB connection issues | Use short, high-quality USB cable; try different ports |
| UART driver missing | Install CH340 or CP2104 drivers |
| Model not ready | Microphone test proceeds independently; integrate after training |
| High latency | Use DMA buffers; optimize tensor arena |
| Memory overflow | Use 256 KB tensor arena (ESP32-S3 has 512 KB) |
