STEP 1: Install Arduino Library (Tools → Manage Libraries)
  Search: "WebSocketsClient"
  Install: "WebSockets by Markus Sattler"

STEP 2: Edit WiFi Credentials
  File: ESP32_MIC_TEST/dora_full_inference.ino
  
  Change these lines:
    #define WIFI_SSID "YOUR_WIFI_NAME"      ← Your WiFi
    #define WIFI_PASS "YOUR_WIFI_PASSWORD"  ← Your password
    #define SERVER_IP "192.168.1.100"       ← Run ipconfig to find IP

STEP 3: Upload to ESP32
  - Connect ESP32 via USB
  - Board: ESP32S3 Dev Module
  - Port: COM11 (check Device Manager if different)
  - Click Upload
  - Wait for "Hard resetting via RTS pin..."

STEP 4: CLOSE Arduino Serial Monitor!
  ⚠️  IMPORTANT: Serial Monitor blocks the COM port
  The bridge cannot connect if Serial Monitor is open

PROBLEM                         → SOLUTION
───────────────────────────────────────────────────────────────────────────

Dashboard shows "DEMO MODE"     → Check ESP32 connected via USB
                                  Verify bridge running (Terminal 1)
                                  Check correct COM port in bridge

"Port COM11 is busy"            → Close Arduino Serial Monitor
                                  Close Device Manager if port open
                                  Restart bridge (Terminal 1)

Voice orb not responding        → Check microphone wiring:
                                    SCK → GPIO4
                                    WS  → GPIO5
                                    SD  → GPIO6
                                    VDD → 3.3V
                                    GND → GND
                                    L/R → GND

RMS stuck at 1.0                → Hardware issue - verify:
                                  - GPIO pins correct
                                  - Soldering connections
                                  - VDD = 3.3V (measure with multimeter)
                                  - Try different GPIO pins

WebSocket connection failed     → Make sure Terminal 1 running first
                                  Check output shows "port 8080"
                                  Firewall not blocking port 8080
