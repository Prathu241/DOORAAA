STEP 2: WIRE YOUR MICROPHONE (15-20 minutes)
─────────────────────────────────────────────
Follow: CONNECTIONS_YOUR_SETUP.md

6 Connections to make:
┌─ RED wire:   ESP32 3.3V    → INMP441 VCC (pin 6)
├─ BLACK #1:   ESP32 GND     → INMP441 GND (pin 1)
├─ BLACK #2:   ESP32 GND     → INMP441 L/R (pin 2)      ← IMPORTANT: 2 GND wires
├─ YELLOW:     ESP32 GPIO 4  → INMP441 SCK (pin 3)
├─ GREEN:      ESP32 GPIO 5  → INMP441 WS (pin 5)
└─ BLUE:       ESP32 GPIO 6  → INMP441 SD (pin 4)

Safety Check:
  ✓ No RED touching BLACK
  ✓ All wires firmly in breadboard
  ✓ Pin labels match


STEP 3: FLASH MICROPHONE FIRMWARE (10 minutes)
───────────────────────────────────────────────
1. Open Arduino IDE (download from arduino.cc if needed)

2. New Sketch → Copy mic_test.ino contents

3. Select Board:
   Tools → Board → Search "ESP32-S3"
           → ESP32-S3 Dev Module

4. Select Port:
   Tools → Port → COMx (ESP32 appears here when USB connected)

5. Upload:
   Sketch → Upload (or Ctrl+U)
   Wait for: "Leaving... Hard resetting via RTS pin"
