ROOT CAUSE
════════════════════════════════════════════════════════════════════════════════

ESP32 is not responding to upload commands. Usually:
  - USB cable loose or bad
  - COM port driver issue
  - ESP32 bootloader not in upload mode
  - USB power insufficient


STEP 1: RESTART ESP32 (Try First)
════════════════════════════════════════════════════════════════════════════════

1. Unplug USB cable from ESP32
2. Wait 3 seconds
3. Plug back in
4. In Arduino IDE: Sketch → Upload (Ctrl+U)

If that works: DONE! ✓

If not: Continue to Step 2


STEP 2: RESET ESP32 TO BOOTLOADER
════════════════════════════════════════════════════════════════════════════════

Your ESP32-S3 has 2 buttons. Do this WHILE uploading:

1. Start upload: Sketch → Upload (Ctrl+U)

2. When you see "Connecting..." in Arduino IDE:
   - Hold the BOOT button (small button labeled BOOT)
   - Keep holding it for 2 seconds
   - Release

3. Arduino IDE should now detect ESP32 and upload

Common button locations on ESP32-S3 DevKit:
  - EN button: Resets device
  - BOOT button: Enters bootloader mode (for upload)
  - Usually on top or bottom edge


STEP 3: TRY DIFFERENT USB SETTINGS
════════════════════════════════════════════════════════════════════════════════

If Buttons don't work:

1. Tools → Upload Speed
   Current: 921600 (fast)
   Change to: 115200 (slower)

2. Tools → Port
   Current: COM3
   Check if other COMx ports appear

3. Try upload again


STEP 4: TRY DIFFERENT USB PORT
════════════════════════════════════════════════════════════════════════════════

If COM3 still fails:

1. Unplug USB cable
2. Wait 2 seconds
3. Plug into DIFFERENT USB port on your computer
4. Arduino IDE → Tools → Port
5. Select new COMx that appears
6. Try upload


STEP 5: CHECK DEVICE MANAGER
════════════════════════════════════════════════════════════════════════════════

Windows-specific:

1. Right-click Start → Device Manager
2. Look for:
   - "COM & LPT Ports" section
   - Look for "CH340", "CP2104", or "USB Serial"
   - COM3 should be listed

3. If you see "Unknown Device" or "!" mark:
   - Right-click → Update driver
   - Choose "Browse my computer for drivers"
   - Select "Let me pick from a list"
   - Choose appropriate USB serial driver

4. Restart Arduino IDE and try again
