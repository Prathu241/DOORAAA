STEP 1: GENERATE BINARY FILE (Arduino IDE)
════════════════════════════════════════════════════════════════════════════════

1. Arduino IDE: Open mic_test.ino sketch

2. Click: Sketch → Export Compiled Binary

3. Wait 10-15 seconds for completion

4. Click: Sketch → Show Sketch Folder

5. You should see files including:
   mic_test.ino.esp32s3.bin  ← THIS ONE

6. Copy this file path or remember the filename


STEP 2: COPY BINARY TO ESP32_MIC_TEST FOLDER
════════════════════════════════════════════════════════════════════════════════

Your .bin file location (from Step 1):
  Typically: C:\Users\PRATHAM\Arduino\libraries\... or similar

Target location:
  c:\Users\PRATHAM\DORA_MIXED-net\ESP32_MIC_TEST\

Method:
  1. Windows Explorer: Locate mic_test.ino.esp32s3.bin
  2. Copy (Ctrl+C)
  3. Navigate to: c:\Users\PRATHAM\DORA_MIXED-net\ESP32_MIC_TEST\
  4. Paste (Ctrl+V)

Result: .bin file now in ESP32_MIC_TEST folder


STEP 3: RUN FLASH SCRIPT
════════════════════════════════════════════════════════════════════════════════

PowerShell Method (Easiest):

1. Open PowerShell (right-click → Open PowerShell here)

2. Go to the folder:
   cd c:\Users\PRATHAM\DORA_MIXED-net\ESP32_MIC_TEST\

3. Run the flash script:
   .\FLASH_SIMPLE.ps1

4. Script will:
   ✓ Find your .bin file automatically
   ✓ Connect to COM3
   ✓ Flash the firmware
   ✓ Tell you when done


Manual Method (If script doesn't work):

1. Open PowerShell, navigate to ESP32_MIC_TEST folder:
   cd c:\Users\PRATHAM\DORA_MIXED-net\ESP32_MIC_TEST\

2. Run:
   python -m esptool -p COM3 -b 921600 --after hard_reset write_flash -z --flash_mode dio --flash_freq 80m --flash_size detect 0x0 "mic_test.ino.esp32s3.bin"

3. Wait for completion (30-60 seconds)

4. You should see:
   "Finished successfully"


IF FLASH FAILS
════════════════════════════════════════════════════════════════════════════════

Error: "Failed to connect"
  → Try: Unplug USB, wait 3 sec, plug back in, try again

Error: "No port found"
  → Check: Device Manager to see if COM3 exists
  → Try: Different USB port (change -p COM3 to -p COM4, etc.)

Error: "Write error"
  → Try: Slower speed (change -b 921600 to -b 115200)
  → Command: python -m esptool -p COM3 -b 115200 --after hard_reset write_flash -z --flash_mode dio --flash_freq 80m --flash_size detect 0x0 "mic_test.ino.esp32s3.bin"

Still failing:
  → Report the exact error message


STEP 4: VERIFY FLASH SUCCESS
════════════════════════════════════════════════════════════════════════════════

After flash completes:

1. Arduino IDE: Tools → Serial Monitor

2. Set baud rate: 9600 (bottom-right)

3. You should see within 2 seconds:
   =====================================================
   DORA MICROPHONE TEST - ESP32-S3 + INMP441
   =====================================================
   ✓ I2S initialized successfully!
   Listening for audio...

4. If you see this: FLASH WAS SUCCESSFUL! ✓

5. If you see nothing: Try unplugging USB and plugging back in


STEP 5: MICROPHONE TEST
════════════════════════════════════════════════════════════════════════════════

In Serial Monitor:

1. Wait for stable output (5 seconds)

2. SILENT TEST:
   Observe values in Serial Monitor
