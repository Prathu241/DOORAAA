        Time: 1 min
        Status: ___________

        Run: ipconfig (PowerShell)
        Record: IPv4 Address: ___________________
        Time: 1 min
        Status: ___________

PHASE 2: MICROPHONE TEST (Duration: 15 minutes)
════════════════════════════════════════════════════════════════════════════════

Objective: Verify microphone is capturing audio correctly

Sub-tasks:

  ☐ 2.1 - Open Arduino IDE
        Action: Launch Arduino IDE 2.0+
        Reference: None
        Time: 1 min
        Status: ___________

  ☐ 2.2 - Install/verify ESP32 board support
        Go to: Tools → Board Manager → Search "ESP32"
        Install: ESP32 by Espressif Systems (if needed)
        Time: 5 min (or instant if already installed)
        Status: ___________

  ☐ 2.3 - Load microphone test sketch
        File → Open → ESP32_MIC_TEST/mic_test.ino
        Reference: ARDUINO_SETUP_QUICK.txt
        Time: 1 min
        Status: ___________

  ☐ 2.4 - Configure Arduino IDE
        Select Board: Tools → Board → ESP32-S3 Dev Module
        Select Port: Tools → Port → COMx (your port)
        Select Speed: Tools → Upload Speed → 921600
        Time: 2 min
        Status: ___________

  ☐ 2.5 - Upload firmware
        Button: Click Upload (Ctrl+U)
        Wait for: "Leaving... Hard resetting via RTS pin"
        Expected: "Upload successful" message
        Time: 2 min
        Reference: ARDUINO_SETUP_QUICK.txt (Part 7)
        Status: ___________

  ☐ 2.6 - Open Serial Monitor
        Tools → Serial Monitor (Ctrl+Shift+M)
        Verify: Baud rate is 9600 (bottom-right)
        Should see: Startup messages from microphone test
        Time: 1 min
        Status: ___________

  ☐ 2.7 - Silence test (10 seconds)
        Action: Sit quiet and observe Serial Monitor
        Record: RMS value: ___________  Peak: ___________
        Expected: RMS 30-60, Peak 50-100
        Status: ___________

  ☐ 2.8 - Speech test (5 seconds)
        Action: Speak "DORA" clearly into microphone
        Record: RMS value: ___________  Peak: ___________
        Expected: RMS 150-400, Peak 300-800 (should be much higher!)
        Status: ___________

  ☐ 2.9 - Clap test (3 seconds)
        Action: Clap loudly near microphone
        Record: Peak value: ___________
        Expected: Peak > 800-1000 (sharp spike)
        Status: ___________

✅ PHASE 2 COMPLETE when:
   - Firmware uploaded successfully
   - Serial Monitor shows stable output
   - Silence test: low values
   - Speech test: values jump 3-5x higher than silence
   - Clap test: peak spikes to 1000+
