⚡ QUICK START - 7 PHASES
════════════════════════════════════════════════════════════════════════════════

PHASE 1: HARDWARE SETUP (10 min)
────────────────────────────────
□ Wire INMP441 microphone to ESP32-S3 using 6 jumper wires
□ Verify power supply (3.3V on VDD pin)
□ Get your computer's IP address for server connection
□ Note: Follow ESP32_MIC_TEST/WIRING_STEPS_SIMPLE.txt exactly

Key File: WIRING_STEPS_SIMPLE.txt
Wiring Summary:
  ESP32 3.3V  → INMP441 VCC
  ESP32 GND   → INMP441 GND & L/R (both pins)
  ESP32 GPIO4 → INMP441 SCK
  ESP32 GPIO5 → INMP441 WS
  ESP32 GPIO6 → INMP441 SD


PHASE 2: MICROPHONE TEST (15 min)
──────────────────────────────
□ Open Arduino IDE
□ Load mic_test.ino from ESP32_MIC_TEST/mic_test.ino
□ Select board: ESP32-S3 Dev Module
□ Select port: Your COM port
□ Upload sketch (Ctrl+U)
□ Open Serial Monitor (Ctrl+Shift+M)
□ Test microphone response: silence → speak "DORA" → clap
□ Verify RMS values jump 3-5x when speaking (NOT stuck at ~0)

Success Criteria:
  - Silence test: RMS ~30-60, peak ~50-100
  - Speech test: RMS ~200-300, peak ~400-600
  - Values change clearly between tests


PHASE 3: MODEL VALIDATION (5 min)
──────────────────────────────
□ Verify trained model exists:
  trained_models/DORA/tflite_stream_state_internal_quant/stream_state_internal_quant.tflite
□ Check file size: 200-500 KB (quantized TFLite model)
□ Test load in Python: interpreter.allocate_tensors() should work

Success Criteria:
  - File exists at path
  - Size is 200-500 KB
  - Loads without error in TensorFlow Lite


PHASE 4: START DASHBOARD SERVER (5 min)
────────────────────────────────────
□ In PowerShell, run:
  cd dashboard
  python server.js
□ Server should start at: http://localhost:8765
□ Open browser: http://localhost:8765

Success Criteria:
  - Server running message appears
  - Dashboard accessible in browser
  - No connection refused errors


PHASE 5: FULL FIRMWARE DEPLOYMENT (30 min)
──────────────────────────────────────
Option A - Simple Approach (start with this):
  □ Use extended version of mic_test.ino that streams to server
  □ Add WiFi code to connect to your network
  □ Add WebSocket code to send audio to dashboard
  
Option B - Advanced (if complete firmware available):
  □ Use dora_firmware/main/main.c with ESP-IDF
  □ Includes TFLite inference on device
  □ Streams results back to server

For Option A:
  1. Update firmware with:
     #define WIFI_SSID "YOUR_NETWORK"
     #define WIFI_PASS "YOUR_PASSWORD"
     #define SERVER_IP "192.168.1.100"  ← Your IP from Phase 1
  2. Upload same as Phase 2
  3. Monitor Serial Monitor for connection messages


PHASE 6: CONNECTIVITY VERIFICATION (5 min)
────────────────────────────────────────
□ Serial Monitor should show:
  [WiFi] Connecting to "YOUR_NETWORK"...
  [WiFi] Connected! IP: 192.168.1.50
  [WS] Connecting to ws://192.168.1.100:8765
  [WS] Connected!

□ Dashboard server should show:
  [stream] Client connected from 192.168.1.50

Success Criteria:
  - WiFi connects within 10 seconds
  - WebSocket connection established
  - Server shows client connected


PHASE 7: END-TO-END TESTING (10 min)

□ Speak "DORA" clearly into microphone
□ Dashboard should receive audio stream or detection result

□ Monitor for 5 minutes - no crashes

Success Criteria:
  - Keyword "DORA" detected 85%+ of the time
  - Other words do NOT trigger detection
  - System stable for 5+ minutes
  - Latency < 600ms average

🆘 TROUBLESHOOTING QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════════

"Port not found":
  → Unplug USB, wait 3 sec, plug back in
  → Check Tools → Port, should see new COM port

Serial shows garbage:
  → Check baud rate: bottom-right of Serial Monitor should be 9600
  → Click dropdown and select 9600

Microphone values stuck at 0:
  → Check wiring, especially GPIO 4/5/6
  → Measure VDD-GND: should be 3.3V ± 0.1V
  → Try different USB cable for more power

WiFi won't connect:
  → Check SSID and password (case-sensitive!)
  → Verify WiFi is 2.4GHz (not 5GHz)
  → Try restarting router

WebSocket connection fails:
  → Run ipconfig to find correct server IP
  → Check server is running (python server.js)
  → Verify port 8765 not blocked by firewall

For full troubleshooting, see: QUICK_COMMANDS.txt or TESTING_PROTOCOL.md
