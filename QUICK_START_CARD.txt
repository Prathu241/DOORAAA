┌──────────────────────────────────────────────────────────────┐
│ 🔧 BEFORE STARTING (ONE-TIME SETUP)                          │
└──────────────────────────────────────────────────────────────┘

1. Install Arduino libraries:
   Tools → Manage Libraries → Search "WebSocketsClient"
   Install: "WebSockets by Markus Sattler"

2. Edit firmware WiFi settings:
   Open: ESP32_MIC_TEST/dora_full_inference.ino
   Change:
     #define WIFI_SSID "YOUR_WIFI_NAME"
     #define WIFI_PASS "YOUR_WIFI_PASSWORD"
     #define SERVER_IP "192.168.1.100"  // Run: ipconfig

3. Upload to ESP32:
   - Connect ESP32 via USB
   - Select Board: ESP32S3 Dev Module
   - Select Port: COM11 (check Device Manager)
   - Click Upload
   - Wait for "Hard resetting via RTS pin..."

4. IMPORTANT: Close Arduino Serial Monitor!
   (Serial Monitor blocks COM port, bridge won't work)

┌──────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                           │
└──────────────────────────────────────────────────────────────┘

Problem: Dashboard shows "DEMO MODE"
Fix: Check ESP32 connected, bridge running on correct COM port

Problem: "Port COM11 is busy"
Fix: Close Arduino Serial Monitor completely

Problem: Voice orb not responding
Fix: Check microphone wiring, verify RMS level changes

Problem: RMS stuck at 1.0
Fix: Hardware issue - check GPIO pins, re-upload firmware

Problem: WebSocket connection failed
Fix: Make sure Terminal 1 (bridge) is running first

┌──────────────────────────────────────────────────────────────┐
│ 📊 DASHBOARD FEATURES                                        │
└──────────────────────────────────────────────────────────────┘

VOICE ORB (top-left):
  - Blue → Idle, waiting for audio
  - Green → Voice detected, listening
  - Red → "DORA" detected with high confidence

SYSTEM METRICS:
  - CPU: Processing load (target < 10%)
  - RAM: Memory usage (out of 256KB)
  - Flash: Model size on ESP32

MICROPHONE STATUS:
  - RMS Level: Audio intensity (40-60 silent, 200-300 speaking)
  - Peak: Maximum amplitude
  - Samples: Total audio frames captured

DETECTION GRAPH:
  - Green line: Confidence score (0.0 - 1.0)
  - Red dashed: Threshold at 0.7
  - Shows last 50 detections

DETECTION LOG:
  - Time: HH:MM:SS timestamp
  - Confidence: Model score (0.85-0.99 typical)
  - Latency: Response time in ms
  - Verdict: TP (true) or FP (false)
